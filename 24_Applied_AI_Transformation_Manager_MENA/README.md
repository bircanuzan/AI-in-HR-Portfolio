# Project 24 — Applied AI Transformation Manager (MENA): Enterprise Agentic AI Rollout and Value Capture

**Independent project simulation aligned with Cognition's Applied AI Transformation Manager job description.** This is **not** a Cognition/Devin enterprise customer deployment, not a claim of BCG/Bain/McKinsey service, not an SWE professional employment claim, and not real customer consumption data.

## Plain-English objective
Design a delivery and operating model for introducing an AI coding agent to thousands of software engineers, support enterprise executive decisions, and calculate conservative *potential* capacity value without claiming real cash savings.

## Contents
- [01 Enterprise discovery and value targeting](01_Enterprise_AI_Discovery_and_Value_Targets.md): customer sponsor interviews, use-case value prioritization, measurable hypotheses
- [02 Agentic AI operating model and CoE](02_Agentic_AI_Operating_Model_and_Centre_of_Excellence.md): account RACI, product/security/engineering ownership, controls and enablement
- [03 Engineering rollout and adoption plan](03_Engineer_Onboarding_and_Rollout_Playbook.md): pilot, cohorts, training, telemetry, partner delivery and support
- [04 Value realization dashboard and governance](04_Consumption_Value_Metrics_and_Executive_Reporting.md): business reporting, sensitivity model, risk and steering committee
- [Synthetic usage casebook](data/synthetic_accounts.csv), [Python illustrative calculator](src/value_capture.py), [tests](tests/test_value_capture.py)

## Run
Python 3.10+; no external dependencies and no Cognition credentials.
Run: python src/value_capture.py
Run tests: python -m unittest discover -s tests -v

## Skills demonstrated
Enterprise transformation, customer value strategy, agentic AI operating model, CoE governance, executive workshops, program delivery, technical enablement for engineers, onboarding thousands at scale, consumption and adoption KPI definitions, realized-value measurement plan, account expansion and risks.

## Critical limitations
No model execution, Devin integration, actual engineering rollout or verified customer financial results. Synthetic assumptions are stated in every value model. A reduction in engineering task time does not itself establish productivity or cash savings; finance and engineering leadership must validate sustained outcomes and actual economic realization.
