# Audience-specific, interactive Copilot workshop designs
**Design artefacts — not records of sessions actually delivered.** A facilitator must verify actual licences, tenant features, permissions and enabled apps before running any demo.

## A. End users — 90-minute applied lab
**Audience:** HR specialists, finance analysts and operations coordinators (fictional; 12–20 participants per proposed group).

| Minutes | Activity | Observable action | Evaluation |
|---|---|---|---|
| 0–10 | Baseline pulse | List one repetitive task and one quality risk | Baseline survey |
| 10–20 | Safe-work orientation | Distinguish permitted from sensitive data; identify hallucination signs | Quick 3-question check |
| 20–35 | Outlook/email use case | Draft a response using a fictional source note | Check each statement against source |
| 35–55 | Excel/Word or Chat task | Build a variance note or learning plan using fictional data | Structured rubric |
| 55–70 | Teams/meeting follow-up | Produce action register from fictional notes | Check owners dates and missing items |
| 70–85 | Breakout pairs and peer QA | Critique outputs; remove unsupported claims | Two independent checks |
| 85–90 | Transfer-to-work commitment | Identify one permitted trial task | 2-week action follow-up |

**Outcome:** Participants should demonstrate a safe, verifiable draft and explain when not to trust an AI output. No result or participation claimed.

## B. AI champions — 120-minute peer-coaching lab
**Audience:** designated function champions (fictional).
- 0–20: workflow discovery; map AS-IS task and friction.
- 20–40: decompose one function-specific task into source, user, draft, validation and escalation.
- 40–70: create role-specific prompt with constraints and acceptable outputs, review against source.
- 70–90: challenge with missing or contradictory data; document when to stop and ask a human.
- 90–105: plan office-hours, help channel, example library, inclusion and accessibility.
- 105–120: assess champion's teach-back using 10-point rubric (accuracy 4, safe handling 3, relevance 2, clarity 1).

**Champion responsibilities (proposed):** two office hours monthly, collect questions, log quality defects, share approved examples, route permission/security questions to IT, never self-authorize new data access.

## C. Executive decision clinic — 60 minutes
**Audience:** Directors, VPs, MDs and decision owners, fictitious.
- 0–10: value hypotheses: time, quality, throughput and employee capability.
- 10–25: executive briefing exercise: compare Copilot output to original board memo.
- 25–40: select two use cases via impact × feasibility × risk matrix.
- 40–50: governance decisions: data visibility, licence readiness, policy, human approval and accountability.
- 50–60: decisions: sponsor, success threshold, pilot population, review date, escalation and stop/go criterion.

**Executive output:** draft scorecard with accountable owners, approval and pilot constraints—not an assumption that every executive personally uses identical in-app capabilities.

## Universal facilitation checks
Every exercise needs a pre-approved fictional dataset, expected output structure, verification checklist, user accessibility, a stop condition and a fallback if required Copilot features are not licensed. Session plans are drafts, not attendance records or customer testimonials.
