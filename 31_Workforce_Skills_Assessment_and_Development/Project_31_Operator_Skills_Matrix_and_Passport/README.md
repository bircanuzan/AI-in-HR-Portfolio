# Project 31 — Operator Skills Matrix and Skill Passport

## Business problem
A production operation needs a consistent, auditable method to determine what operators must know, how proficiency should be demonstrated, what gaps exist and how training effectiveness will be rechecked.

## Example scope and method
1. Group roles and critical workstation tasks.
2. Define an observable 1–4 proficiency scale and role targets.
3. Map tasks to evidence, assessor, rubric and safety gates.
4. Record fictional baseline ratings and calculate gaps as max(target - actual, 0).
5. Prioritize coaching and certification pathways with safety-critical requirements taking precedence.
6. Issue individual skill passports, then repeat approved assessments after training.

Practical exercises, machinery rules, certifications and safety-critical sign-off require plant-approved technical subject-matter expertise.
