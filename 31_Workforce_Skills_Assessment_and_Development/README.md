# Workforce Skills Assessment & Development

**Project 31:** [Operator Skills Matrix and Skill Passport](Project_31_Operator_Skills_Matrix_and_Passport/)

A demonstration of how to define role-specific operator competencies, plan practical observations, identify skill gaps and recommend training and post-training rechecks.

**Status:** Fictional portfolio case. The skill targets, employee codes and assessment results are illustrative. Plant-specific test items and safety decisions must be approved by a qualified technical SME. No employee was actually assessed.
