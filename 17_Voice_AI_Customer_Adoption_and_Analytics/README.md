# Project 17 — ElevenLabs-style AI Adoption & Enablement Analytics

**Independent, synthetic portfolio case study.** Aligns with the ElevenLabs Adoption Strategist - Middle East and Deployment Strategist UAE skill requirements. It is not an ElevenLabs customer account, an audit of live ElevenAgents, a real customer success result or a connected dashboard.

## Business scenario
A fictional portfolio of UAE enterprise accounts has been onboarded to a voice-agent product. Analyse activation, adoption, conversation success and cost indicators; create a 30/60/90-day enablement plan; design a scalable agent configuration audit and executive value narrative.

## Deliverables
- synthetic_data/accounts.csv — completely made-up organisations, periods and activity counts.
- src/adoption.py — reproducible CSV analytics with activation, success and handoff metrics.
- tests/test_adoption.py — tests on definitions, denominators and edge cases.
- docs/adoption_playbook.md — scaled rollout, live workshops, enablement packs and governance ownership.
- docs/agent_audit_scorecard.md — prompts, persona, tools, language and success criteria.
- docs/enterprise_value_case.md — discovery-to-value ROI methodology without invented client results.

## Run
Python >=3.10 (standard library only):
1. python src/adoption.py
2. python -m unittest discover -s tests -v

Output is local console text for synthetic records. No live API, customer data or credentials.

## Skills illustrated
SaaS onboarding, adoption and time-to-value, agent audits, stakeholder enablement, product education, customer workshops, metrics definitions, QA, analytics, AI adoption, business case, commercial discovery and cross-functional collaboration.

## Product alignment
ElevenLabs documents conversation analytics for sessions, duration, cost, success/failure/unknown, response latency, errors and languages. This toy dashboard models a subset from fictional input; it does not reflect actual ElevenLabs account reports. Reference: https://elevenlabs.io/docs/eleven-agents/dashboard
