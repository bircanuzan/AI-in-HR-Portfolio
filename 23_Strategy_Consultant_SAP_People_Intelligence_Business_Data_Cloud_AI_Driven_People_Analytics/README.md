# Project 23 — Strategy Consultant: SAP People Intelligence, Business Data Cloud & AI-driven People Analytics

**Independent, fictional consulting portfolio designed against the 3n Strategy Senior Strategy Consultant brief.** No SAP tenant, commercial customer assignment, live report, contract win or certification is represented.

## What this project does in plain language
Define the people analytics strategy for a fictional multinational, translate executive HR questions into clear KPIs and a SAP-aligned solution roadmap, then plan enablement, account development and measurable business outcomes.

## Folder contents
- **01_Discovery_and_People_Analytics_Vision.md** — CHRO workshops, qualitative interviews, mock Qualtrics survey and Miro workshop structure
- **02_KPI_Dictionary_and_Capability_Assessment.md** — workforce KPIs, KPI owners, success definitions and assessment rubric
- **03_SAP_BDC_Datasphere_SAC_Solution_Alignment.md** — SAP SuccessFactors, People Intelligence, Business Data Cloud, Datasphere, SAC and Report Stories architecture assumptions
- **04_Transformation_Roadmap_and_Investment_Case.md** — phases, value case, governance, risks and adoption
- **05_Account_Growth_and_Executive_Presentation.md** — sponsor relationship plan, discovery-to-proposal pipeline and PowerPoint storyboard
- **data/synthetic_workforce.csv**, **src/people_kpis.py**, **tests/test_people_kpis.py** — locally runnable, transparent KPI demonstration

## Try the analytic example
Python 3.10 or higher; no dependencies, API keys or SAP licence needed. Run python src/people_kpis.py, then python -m unittest discover -s tests -v.

## Product positioning and delivery constraints
SAP People Intelligence is an additional offering in SAP Business Data Cloud that connects HR, skills and business data. Before use, customer teams must obtain applicable licences, provision Business Data Cloud and configure SAP Datasphere, SAP Analytics Cloud and SuccessFactors landscape integration and data access controls. The repo documents strategy **and technical-handoff questions**, not completed tenant configuration.

Source: https://help.sap.com/docs/people-intelligence/people-intelligence/prerequisites-for-using-people-intelligence
