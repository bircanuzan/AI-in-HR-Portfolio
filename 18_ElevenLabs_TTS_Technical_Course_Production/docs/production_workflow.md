# Audio-first technical lesson development — course production workflow

## Learning goal
Explain data leakage and held-out testing to working engineers using a story-led six-minute micro-lesson, screen recording, captioned narration and a practical lab linked to Project 14.

## Storyboard
00:00-00:45 Hook: an impressive accuracy number that may be misleading.
00:45-01:30 State the learner outcome and experiment framing.
01:30-02:30 Show split, fit and held-out evaluation with readable code.
02:30-03:30 Compare baseline and pipeline; avoid hidden leakage.
03:30-04:30 Read per-class outcomes and confusion matrix.
04:30-05:30 Discuss operational caveats (drift, provenance, approvals).
05:30-06:00 Learner challenge and lab handoff.

## Content production steps
1. Curriculum specialist signs off objective and target learner prerequisite.
2. SME validates script terminology, code and limitations.
3. Educator prepares spoken-friendly narration (separate from on-screen code).
4. Voice selection is lawful, licensed and appropriate for the learner audience.
5. Dry-run validation of characters and API settings before any billable synthesis.
6. Any paid synthesis is opt-in, human-reviewed, and followed by correct subtitles.
7. Native-speaker translation and pronunciation QA for every target language, with regional context and learning terminology review.
8. Editor checks timing, pause positions, pronunciation, audible code navigation and accessibility.
9. Lab reviewer confirms walkthrough exactly matches tested environment.
10. Collect user feedback and maintain script/voice/version/revision log.

## Quality and compliance review
- Confirm approved voice ownership, voice-cloning consent and license terms.
- Avoid sensitive learner or customer data in narration.
- Do not infer that text-to-speech alone creates completed instructional video.
- Human review is required for translations and narration.
- Measure learner comprehension using lab checkpoints, not voice quality alone.
- Ensure spoken script, captions and on-screen labels match.
- Check accessibility accommodations including transcript availability and playback controls.
