# Course alignment and source notes

**Reviewed:** 29 October 2026. This project applies course topics to an original fictional HR scenario. It does not verify the author's completion badge, certification or hands-on execution.

## Learning path
[Demonstrate the capabilities of Microsoft Power Automate](https://learn.microsoft.com/en-us/training/paths/demonstrate-capabilities-microsoft-power-automate/) is a beginner path with no prerequisites and two modules.

| Course area | Application in this project | Current evidence |
|---|---|---|
| Cloud versus desktop flows | Select cloud orchestration for a Microsoft 365 request | Design rationale; desktop automation excluded |
| Triggers and actions | Submission starts intake; recurrence checks overdue work | Proposed flow design |
| Approvals and Microsoft 365 services | Forms, SharePoint, Approvals, Outlook and Teams | Architecture and decision branches |
| Copilot-assisted creation and editing | Propose and explain a flow structure with human review | Adoption design; no generated flow claimed |
| Testing and troubleshooting | Normal, rejection, duplicate, timeout and failure scenarios | Planned acceptance criteria |
| Monitoring and optimisation | Track runs, failures, delays and handling effort | Measurement plan |
| Sharing and access | Named owner, backup owner and least-privilege access | Governance requirements |

## Original HR application and extensions
AS-IS/TO-BE mapping, the service ownership model, duplicate protection, privacy decisions, adoption plan and capacity estimates are original case-design additions. They are not represented as course exercises or proven outcomes.

The path also covers desktop automation and document-processing use cases. These are not implemented here. AI Builder, premium services, runtime generative AI and automated letter generation are outside this release; any later extension needs separate suitability and licensing checks.
