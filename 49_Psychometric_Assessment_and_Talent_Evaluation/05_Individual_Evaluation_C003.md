# 05 — Individual Assessment Interpretation & Talent Evaluation Report
**Case C003** | Fictional Senior HR Analyst applicant | **Remote** | **Demo only — Not an employment assessment**

## Decision question
What evidence should HR obtain to assess analytical capability, communication and work-related judgement for an HR analyst role?

## Available evidence — entirely invented
| Source | Fictional index | Report comment |
|---|---:|---|
| Numerical reasoning style | 68 | Lowest among this individual's three arbitrary ability-related fields; should prompt targeted job-task evidence, not a deficit diagnosis |
| Verbal reasoning style | 81 | Higher than this person's other fictional indices; requires validated instrument data before meaningful interpretation |
| Abstract reasoning style | 72 | Insufficient for any claim about general intelligence |
| Planning preference | 85 | Preferred work approach, not measured performance |
| Collaboration preference | 88 | Response-style descriptor, not proven teamwork capability |
| Adaptability preference | 74 | Preference descriptor, not an evidence-based risk prediction |
| Structured interview | 86 | Separate, fictitious contextual input |
| Job-related work sample | 83 | Separate, fictitious contextual input |

**Nonvalidated calculation:** `0.4×68 + 0.35×81 + 0.25×72 = 73.6`. This is **only a spreadsheet/math illustration**, not a psychometric composite, norm, percentile or decision score.

## Professional interpretation boundaries
- **Potential strengths to explore:** the independent work sample and interview suggest a reason to further investigate written communication and data storytelling.
- **Question to resolve:** Can the applicant accurately interpret a practical HR dashboard, numerical variance and workforce metric?
- **Limitations:** no instrument manual, norms, standard errors, adverse-impact data, validation study, actual candidate consent or qualified test-user interpretation. No psychometric recommendation can be made from this demonstration.

## Evidence-based next step
Invite the fictional applicant to complete a consistent, accessible, role-relevant numerical HR reporting exercise scored with preset anchors. A qualified reviewer should interpret any actual psychometric test evidence. HR then makes a documented decision using the full evidence set.

## Candidate feedback draft
“Your fictional case contains different score patterns across areas. Scores need to be interpreted in relation to a validated test and the demands of the job. We would use this information alongside your work example and interview, and we would not treat one number as a definitive measure of your capabilities.”

**Recommendation status:** Further evidence required; **no hire/no-hire recommendation**.
