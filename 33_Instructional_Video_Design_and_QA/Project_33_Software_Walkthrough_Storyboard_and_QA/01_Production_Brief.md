# Instructional video production brief

**Title:** Submit a Request in a Fictional Internal Portal  
**Audience:** New employees  
**Proposed runtime:** 4:00  
**Format:** Screen capture with visual callouts, narration/captions and end-of-video recap  
**Status:** Design sample; no raw client screen recording, voice-over or MP4 exists.

## Observable objective
Learner can describe five stages: open the form, enter required data, review fields, submit, and verify confirmation.

## Proposed source package
1. Client-approved step list and screenshots of an anonymized system.
2. Brand and accessibility guidance.
3. Preferred recording specs and publishing channel.
4. Terminology and review owner.
5. Any required data masking / privacy rules.

## Editing directions
- Prioritize relevant screen areas with brief zoom/callout.
- Do not obscure critical controls.
- Keep edits consistent with the approved user journey.
- Avoid silent fast-forward through tasks learners must remember.
- Provide caption file and script/transcript if commissioned.
- Export settings (resolution, frame rate, format, bitrate) to be agreed with editor and publishing environment.

## Approval gates
G1 inputs complete; G2 storyboard/technical accuracy signed; G3 rough cut learning review; G4 editorial/accessibility QA; G5 final acceptance and handover.

No software vendor brand, client screen or confidential information is included.
