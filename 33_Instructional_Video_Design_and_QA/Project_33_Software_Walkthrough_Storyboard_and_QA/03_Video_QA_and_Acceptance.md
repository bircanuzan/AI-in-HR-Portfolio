# Learning-video QA checklist

**Sample deliverable:** Four-minute fictional software walkthrough.  
**Execution status:** Not executed. No video exists to review.

| QA item | Expected evidence | Status |
|---|---|---|
| Technical accuracy | Approved step list matches demonstrated screen actions | Not tested |
| Objective alignment | Scenes clearly support stated learner outcome | Storyboard only |
| Timing | Scenes total 04:00; no unnecessary sections | Planned |
| Visual clarity | Callouts legible; no obscured controls; controlled zoom | Not tested |
| Audio | Narration intelligible and synchronized; no clipping | Not tested |
| Captions | Correctly timed, readable, reviewed against script | Not tested |
| Accessibility | Captions/transcript and clear hierarchy | Not tested |
| Data/privacy | Test credentials and sensitive content excluded/masked | Not tested |
| File spec | MP4, aspect ratio, runtime, codec and naming agreed | Not tested |
| Revisions | Feedback log, owner, version and approval date captured | Not tested |

## Suggested feedback log schema
Issue ID | Timecode | Severity | Observation | Required change | Owner | Version | Resolution evidence.

## Acceptance and handoff
The commissioning team approves content accuracy; the editor confirms export and technical compliance; the instructional designer reviews learner comprehension. Final deliverable requires a documented pass on the agreed matrix.
