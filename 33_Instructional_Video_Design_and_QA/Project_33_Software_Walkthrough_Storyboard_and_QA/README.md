# Project 33 — Software Walkthrough Storyboard and QA

## Problem
Raw application screen recordings can be lengthy and difficult for beginners to learn from. This case converts a fictional workflow into a short, sequenced learning-video specification.

## Objective
After a four-minute walkthrough, a learner can identify the steps to create, submit and confirm a request in a fictional internal portal.

## Deliverables
- [Production brief and design notes](01_Production_Brief.md)
- [Time-coded storyboard](02_Timecoded_Storyboard.csv)
- [Learning-video QA and acceptance](03_Video_QA_and_Acceptance.md)
- [Production capacity and roles](04_Production_Capacity_Planning.md)

## Role separation
- **Instructional designer:** clarify objective, analyze source, script scenes, design callouts, review learning clarity and track revisions.
- **Technical editor:** edit screen recordings, perform audio work, create captions and export agreed MP4 specifications.
- **Content approver:** validate actual workflow and sign off content/brand.

This is a speculative **portfolio sample**, not a completed contract or finished MP4.
